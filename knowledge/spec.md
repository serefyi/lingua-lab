# Lingua Lab 第一版功能規格

## 產品假設

為因工作或學習需要實用英文的個人學習者，提供短時間、一次聚焦一項技能的練習。這是待使用者回饋驗證的假設，並非已完成的使用者研究。

## 使用流程

1. 選商業英文、學術英文或道地英文分析情境。
2. 選聽、說、讀、寫其中一項技能。
3. 選情境主題、入門／中階／進階程度，以及 3／5／10 分鐘時長。
4. 完成一題，必要時使用提示或重播音訊。
5. 查看依技能與主題提供的自我檢查建議；不提供未驗證的分數。
6. 可選擇在此裝置留存完成摘要，回答文字不保存。

## 功能範圍

- **情境與主題**：商務會議、商務郵件、簡報提案；課堂討論、研究摘要、論文閱讀；禮貌請求、日常對話、自然說法。
- **聽力**：播放瀏覽器合成語音，可重播，並提供可展開文字稿作為輔助。語音及口音因瀏覽器而異。
- **口說**：提供口語情境、句型提示與回答草稿欄位。第一版不錄音、不辨識發音；欄位標示為口說草稿。
- **閱讀**：閱讀短篇英文材料後回答理解問題。
- **寫作**：依照情境寫英文草稿，獲得語氣與內容檢查提示。
- **程度與時間**：程度改變自我檢查提示（目前不改變文章難度）；時長設定倒數計時，時間到仍可繼續作答。
- **回饋**：提供主旨、證據、語氣或自然用法的自我檢查建議，不聲稱自動判分或逐字批改。
- **本機摘要**：使用 `localStorage` 記錄完成總數、技能累計及最近完成日期；不記錄答案，也不傳送到伺服器。使用者可在頁面確認後清除摘要。

## 驗收條件

- 切換情境會更新對應主題；開始後會顯示所選技能、主題、難度並啟動計時。
- 四項技能均呈現各自的練習材料、題目與提示。
- 聽力音訊可播放、重播，且文字稿可用；瀏覽器不支援語音時仍可看文字稿。
- 空白答案不會被標記完成；完成一次後不會重複增加摘要次數。
- 摘要只包含非答案的完成中繼資料，儲存失敗不會阻止練習完成。
- 使用者能在確認後清除本機摘要。
- 手機版與桌面版都能操作選擇器與對話框。
- GitHub Actions 在發布前執行 JavaScript 語法檢查和練習流程測試。
